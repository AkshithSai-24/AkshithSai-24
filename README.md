## 🏛️ Architecture Highlights

### 🔍 Agentic RAG — MCP Architecture
```
User uploads document / asks question
          │
          ▼
   ┌──────────────┐
   │ Streamlit UI │  ← MCP Client
   └──────┬───────┘
          │ MCP Protocol
          ▼
   ┌──────────────┐
   │  MCP Server  │  ← Central Orchestrator
   └──────┬───────┘
          │
    ┌─────┼──────────────┐
    ▼     ▼              ▼
┌────────┐ ┌──────────┐ ┌─────────────────┐
│Ingest  │ │Retrieval │ │ LLMResponseAgent│
│Agent   │ │Agent     │ │  (Gemini LLM)   │
└────────┘ └──────────┘ └─────────────────┘
    │           │
    ▼           ▼
DocumentLoader  FAISS VectorStore
```
