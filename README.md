A high-performance, visually stunning portfolio website built to showcase expertise in **Artificial Intelligence**, **Machine Learning**, and **Generative AI**. This project features a modern dark-themed UI with smooth animations and a responsive design.

---

## 🌟 Key Features

- **Modern UI/UX**: Built with a "Dark Sophisticated" theme using Tailwind CSS and shadcn/ui.
- **Interactive Experience**: Fluid animations and transitions powered by Framer Motion.
- **Dynamic Content**: 
  - **Typewriter Hero**: Rotating roles highlighting core competencies.
  - **Project Showcase**: Filterable project gallery with detailed descriptions and tech stacks.
  - **Experience Timeline**: Interactive internship history with expandable details.
  - **Skills Matrix**: Categorized technical toolkit from LLMs to Blockchain.
- **Fully Responsive**: Optimized for all screen sizes from mobile to ultra-wide monitors.
- **Contact Integration**: Functional contact form with custom mailing service integration.

---

## 🛠️ Tech Stack

### **Frontend & Core**
- **Framework**: React 18 (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Components**: shadcn/ui (Radix UI)
- **Animations**: Framer Motion
- **Icons**: Lucide React

### **State & Data**
- **Routing**: React Router DOM
- **Data Fetching**: TanStack Query (React Query)
- **Forms**: React Hook Form + Zod

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or bun

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/AkshithSai-24/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Environment Setup**
   Create a `.env` file in the root directory and add your mailing service API key:
   ```env
   VITE_MAILING_SERVICE_API_KEY=your_api_key_here
   ```

4. **Run Development Server**
   ```bash
   npm run dev
   ```
